# Responsive Landing Page — Stockroom

A fully responsive product landing page for **Stockroom**, a fictional household inventory and expiry-tracking app. Built with plain HTML, CSS and JavaScript — no frameworks.

## Features

- Sticky frosted-glass navigation bar with backdrop blur
- Full hero section with two CTA buttons and a visual "shelf" component
- Three-column feature grid (auto-adjusts to 2 on tablet, 1 on mobile)
- Numbered "How it works" steps using CSS counters
- Testimonials section with dark background
- Final call-to-action banner with rounded card
- Multi-column footer with product, company and legal links
- Accessible mobile hamburger menu with `aria-expanded` and auto-close on link tap
- `prefers-reduced-motion` support

## Tech Stack

- HTML5 (semantic elements, skip link, ARIA attributes)
- CSS3 (Grid, Flexbox, `clamp()`, custom properties, `backdrop-filter`)
- JavaScript (mobile menu toggle)
- Google Fonts: Bricolage Grotesque, Figtree

## Files

| File | Purpose |
| :--- | :--- |
| `index.html` | Page structure and content |
| `styles.css` | Layout, colours, responsive breakpoints |
| `script.js` | Mobile navigation toggle |

## Run Locally

Open `index.html` in any browser.
